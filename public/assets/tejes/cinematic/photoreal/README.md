# Original Tejas cinematic concept imagery

Generated 17 October 2026 using the built-in OpenAI image-generation tool. These are original AI-created interior design concepts, not photographs of real TEJAS commissions, real construction documents, or evidence of a verified company service.

- `originals/`: all 12 native PNG outputs, preserved without upscaling or overwriting.
- `*-640.webp`, `*-960.webp`, `*-1280.webp`, and native-size WebP: responsive landscape delivery.
- `*-portrait-480.webp` / `*-portrait-640.webp`: deliberately composed portrait crops for narrow screens.
- `manifest.json`: ordered chapter mapping, native sizes, responsive variants, byte sizes, alt descriptions and crop positions.
- `generation-prompts.json`: exact prompt set and generation mode.

Native source sizes are 1672×941 or 1536×1024. No larger-resolution source is claimed. Native-size landscape WebP files together total 3,283,876 bytes; the twelve 640px portrait versions together total 1,411,026 bytes. The UI mounts only the current chapter and its adjacent images. Reading mode lazy-loads later chapters. No original PNG is requested by the page.

## Relationship to the 3D journey
The approved chapter data, camera path, chapter order, document-scroll timeline and editorial layout remain unchanged. Generated imagery is a clearly labelled photographic concept layer sharing that timeline; it is not used as a substitute mesh or a fake interactive room. “View live 3D” reveals the preserved navigable spatial study at the current scroll position. Images have no simulated camera or parallax. Their reversible crossfade is driven by the same chapter progress. Occluded WebGL redraws are skipped while a fully opaque image is shown; camera state continues to follow the unchanged path.

The spatial study retains its original licensed GLB assets. Its material treatment now uses deeper walnut/oak tones, reduced environment fill and correctly interpreted linear normal/roughness maps. Existing original model licences remain in the parent folder.

No gateway, Spoorthi asset, Projects, Services or Contact source was edited for this visual upgrade.
