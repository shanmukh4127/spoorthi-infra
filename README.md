# Spoorthi Infra

## Purpose

Spoorthi Infra is a React-based project for the Spoorthi Infra and Tejes Interiors experiences.

## Tech stack

- React
- React Router
- Vite
- Oxlint

## Current status

Phase 0 is in progress. The routing foundation, global CSS foundation, and project hygiene are set up. Visual design has not started.

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```
